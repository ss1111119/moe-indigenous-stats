# 大專原住民學生統計 — 可機器讀取版

教育部把大專原住民學生的**學門／科系**統計鎖在 PDF 與 Excel 出版品裡，
互動圖表又是 Tableau Public 嵌入、抓不到底層資料。
這個專案把那些出版品解析出來，接上開放資料的全體學生數，
產出可以直接分析的 CSV，以及一份對照報告。

📊 **報告頁**（兩頁，右上角可切換）
- [科系](https://ss1111119.github.io/moe-indigenous-stats/) — 原民生念什麼，跟一般生差多少
- [縣市](https://ss1111119.github.io/moe-indigenous-stats/geography.html) — 原民生離開了哪些縣市，各縣市的學歷存量

- **106–114 學年**科系分析，27 個學門、169 個細學類；校別與族籍別 **104–114 學年**
- 原住民學生 vs 一般生的**結構差異**與**逐年增減趨勢**
- 可切換 6 個等級別（總計／博／碩／學士／二專／五專），全頁圖表同步重算
- 細學類可搜尋、排序、展開看九年走勢；可查 242 所學校任一所
- 另有性別（5 學制）與族籍別（18 族）兩個維度
- 每個數字都標明口徑，不可比的部分明確標記

## ⚠️ 用之前先看這三件事

這些是資料本身的問題，不是程式的 bug。直接拿數字去用會出錯。

| 問題 | 影響 | 已如何處理 |
|---|---|---|
| **109 學年分母缺漏** | `sdata` 該年少了 53,407 人（4.4%）。護理科從 30,063 掉到 1,886，隔年回到 29,975。拿各年總數對校別檔，其餘八年**完全相等**，只有 109 對不上 | 逐個細學類比對 108／110 內插值，**10 類**明顯偏低（護理及助產、藥學、醫學、一般法律、公共關係、視覺藝術等）已在 `trend_major.csv` 留白；全國層級用 `分母完整度` 欄標示。**該年占比一律偏高，勿引用** |
| **`999 其他學門` 不可比** | 分子（出版品）含空大及進修學校、宗教研修學院，分母（`sdata`）只有 140 所大專校院。無科系可歸的學生全堆進 999，使該欄原民數約為全體的 1/3，而整體水準只有 2% | `可比` 欄標成 `False`，並排除在結構占比的分母外 |
| **106 以前接不上** | `sdata` 103–105 用學科標準分類**第 4 次修正**的 6 碼代碼，106 起改**第 5 次修正**的 8 碼 | 學門／科系分析一律從 106 學年起算 |

還有一個環境問題：**`stats.moe.gov.tw` 與 `segisws.moi.gov.tw` 的憑證都缺
Subject Key Identifier**，Python 3.13 起 `VERIFY_X509_STRICT` 預設開啟會拒絕連線。
兩支 fetch 腳本只關掉 `VERIFY_X509_STRICT` 這一個 flag——**憑證鏈與主機名稱驗證仍然生效**，
放寬的只有「憑證欄位是否完全符合 RFC 5280」那層形式檢查。
（先前的作法是 `ssl._create_unverified_context()`，那等同 `curl -k`，已改掉。）

## 快速開始

```bash
pip install -r requirements.txt

python fetch.py                # 開放資料（約 46MB）
python fetch.py ebooks sdata   # 出版品 xls/xlsx + 各校科系別概況（約 25MB）
python fetch_segis.py          # 原住民成年人口教育程度（SEGIS，約 53MB）
python fetch_segis_college.py  # 行政區大專校院統計（SEGIS，約 100KB，一次取回）

python build.py                # 校別／年級層級
python build_field.py          # 學門與細學類層級
python build_trend.py          # 逐年指數序列
python build_gender.py         # 性別結構（等級別層級）
python build_ethnicity.py      # 族籍別（16 族 × 等級別 × 性別）
python build_geography.py      # 縣市：出生戶籍地 → 學校所在地的流動
python build_education.py      # 縣市：原住民成年人口學歷結構（存量）
python build_receiving.py      # 鄉鎮市區：承接端（並自動與 A1-6a 逐縣市比對）
python build_ladder.py         # 鄉鎮市區：四學制就學階梯（367 → 87）
python export_report.py        # 報告頁 → docs/

python -m http.server -d docs 8000   # 本機預覽
```

報告頁要 fetch `data/*.json`，**不能直接用 `file://` 開**，得起一個 server。

`docs/` 是 GitHub Pages 的發佈目錄，內容全部由 `export_report.py` 產生，不要手改：
`report_template.html` → `docs/index.html`、`geography_template.html` → `docs/geography.html`、
`site_style.css` → `docs/style.css`。**兩頁共用同一份 CSS**——各自內嵌一份的話，
改了一邊忘了另一邊不會有任何錯誤訊息。

`out/` 的 CSV 已經放進版控，**不跑 pipeline 也能直接用**。
`data/`（原始檔 71MB）沒有進版控，`fetch.py` 可完整重建。

## 縣市維度：流出、承接、存量

上面全部是全國層級的科系／校別／性別／族籍別。這一節是另一根軸——**縣市**，
由三塊組成，回答同一個問題的三個階段，成果是第二個報告頁
[縣市](https://ss1111119.github.io/moe-indigenous-stats/geography.html)。

**為什麼另開一頁而不是加在原本那頁**：原頁的核心互動是等級別切換器，一按全頁重算；
而存量那塊根本沒有等級別這個維度，塞進去會變成一個對主控制項毫無反應的死區塊。
加上原頁完全沒有地理維度，這不是「多加一塊」，是開一根新的座標軸。

### 一、流出與承接（`build_geography.py`）

原民生從哪個縣市來、到哪個縣市念書。114 學年，全國 27,347 人：

| 縣市 | 出生戶籍地 | 學校所在地 | 淨流動 | 就學戶籍比 |
|---|---:|---:|---:|---:|
| 臺東縣 | 3,909 | 792 | **−3,117** | **20.3%** |
| 花蓮縣 | 4,371 | 1,649 | −2,722 | 37.7% |
| 南投縣 | 1,588 | 378 | −1,210 | 23.8% |
| 屏東縣 | 2,978 | 2,013 | −965 | 67.6% |
| 桃園市 | 2,901 | 2,880 | −21 | 99.3% |
| 臺北市 | 1,105 | 4,554 | **+3,449** | 412.1% |

**臺東縣有八成的原民生離開臺東就學。** 承接端的人數集中在臺北、臺中、高雄、臺南——
但**人數會被縣市大小帶著跑**。改看集中倍數（原民占全國比 ÷ 一般生占全國比）就翻轉了：

| 縣市 | 集中倍數 114 | |
|---|---:|---|
| 臺東縣 | 6.93 | 相對超額承擔 |
| 花蓮縣 | 4.96 | |
| 屏東縣 | 3.15 | |
| 臺北市 | **0.76** | 人數最多，比例上卻偏少 |
| 新竹市 | 0.37 | 最低 |

臺北市收的原民生人數全國最多，但它承接的原民生比例**低於**它承接一般生的比例。
真正超額承擔的還是原鄉縣市自己。這也是本站其他頁面一貫的紀律——**比結構占比，不比人數**。

「就學戶籍比」＝學校所在地人數 ÷ 出生戶籍地人數。**低於 100% 才讀得成留存率**；
高於 100% 是淨承接（臺北市 412% 不是「留存 412%」）。

★ **`A1-5`（出生戶籍地）與 `A1-6b`（學校所在地）是同一個母體**——11 個學年、
6 個等級別的總計兩兩相等（腳本逐等級別驗證），所以淨流動是精確值，不是兩份資料硬湊。
`A1-6a`（不含宗教研修、空大進修學校）**範圍不同，不可拿去相減**，只當參考欄輸出。

### 二、存量（`build_education.py`）

幾十年下來，各縣市的原住民成年人口學歷結構長什麼樣。113 年底，
全國 15 歲以上原住民 **490,336 人**，專科以上 **35.0%**：

| | 專科以上 | 大學以上 | 國中以下 |
|---|---:|---:|---:|
| 臺北市 | 53.9% | 42.9% | 14.2% |
| 新北市 | 39.1% | 29.8% | 21.8% |
| 花蓮縣 | 32.4% | 23.1% | 29.4% |
| 臺東縣 | 29.3% | 20.6% | 35.8% |

都會縣市高、原鄉低，跨度超過 24 個百分點。**流出最嚴重的臺東，存量學歷也最低；
承接最多的臺北，存量學歷最高。**兩塊要擺在一起看，單獨一塊都只是一張排行榜。

### 三、承接端的鄉鎮市區（`fetch_segis_college.py`／`build_receiving.py`）

縣市層級講不出縣市內部的差別。SEGIS《行政區大專校院統計》把承接端降到鄉鎮市區，
而且分子與分母在同一列（`NA_STU_CNT` 原住民學生數、`STU_CNT` 全體學生數），
占比不需要外部對照表。

全國有大專校院的鄉鎮市區只有 **87 個**，分布在 **21 個縣市**。114 學年：

| 鄉鎮市區 | 原民生 | 占當地大專學生 |
|---|---:|---:|
| 桃園市中壢區 | 1,137 | 2.0% |
| 臺北市大安區 | 1,102 | 1.3% |
| 花蓮縣壽豐鄉 | 845 | 8.4% |
| 花蓮縣花蓮市 | 804 | **16.1%** |
| 臺東縣臺東市 | 792 | **14.7%** |

**人數最多的在六都，比重最高的在東部。**這跟縣市層級看到的是同一個現象，
但鄉鎮層級才看得出承接其實高度集中在少數幾個校區所在地。

⚠️ 這份資料的四個限制：

1. **只有一個學年，是快照不是趨勢。** 開放服務端點的 `oCode` 由主題代碼、
   統計單元代碼與資料格式組成，**不含年度**；`OpenService.asmx` 的三個方法都沒有
   時間參數。實測 99–114 共 16 個學年的產品頁回傳**完全相同的 oCode**，
   其資料 `INFO_TIME` 全是 `114Y`。歷年只能走平台需登入的檔案下載流程。
2. **端點回傳的是「平台當下最新一期」，不是固定的 114 學年。** 明年會變成
   115 學年而腳本不會察覺，所以學年一律取自回應的 `INFO_TIME`，程式與頁面都不寫死。
3. **與教育部出版品同源，不是交叉驗證。** 這份的原始統計機關就是教育部統計處。
   縣市加總與 `A1-6a`（不含空大與宗教研修學院）**實測逐縣市完全相符、全國同為
   25,613 人**——那證明的是我們沒把資料讀錯，不是兩個獨立來源互相印證。
   它唯一的價值是鄉鎮市區粒度。
4. **小分母要小心。** 有 4 個鄉鎮的全體大專學生不足 1,000 人，占比會被少數個案
   放大，頁面上標 `＊`。另有 1 個鄉鎮（花蓮新城）學校數與學生數皆為 0 但
   上學年畢業生 210 人——那是停辦的校區，占比輸出空值而非 0。

### 四、就學階梯（`build_ladder.py`）

同一批 SEGIS 資料另有國小、國中、高級中等學校三筆，欄位命名與大專那筆完全相同。
四階合起來回答「原民生為什麼要離開戶籍地」——現有的流動分析只呈現結果，
這條線是結構性的原因。114 學年：

| 學制 | 有該階學校的鄉鎮市區 | 有原民生的 | 原民生 | 年級數 |
|---|---:|---:|---:|---:|
| 國小 | 367 | 363 | 52,051 | 6 |
| 國中 | 357 | 339 | 24,513 | 3 |
| 高中職 | 206 | 197 | 20,398 | 3 |
| 大專 | **87** | 86 | 25,613 | 不一 |

全國共 368 個鄉鎮市區。**義務教育近乎全覆蓋，高等教育只剩 87 個。**

⚠️ 這份的四個限制：

1. **人數不可跨階相比。** 各學制年級數不同——國小的 52,051 人涵蓋 6 個年級、
   高中職的 20,398 人涵蓋 3 個年級，直接相比會讓人誤以為流失了六成。
   可比的是鄉鎮市區數，每個鄉鎮在每一階都只算一次。`ladder_township.csv`
   帶了「年級數」欄，就是為了讓拿到 CSV 而沒讀這段的人也看得到這個限制。
2. **四階是同一時點的橫斷面，不是同一批人的追蹤。** 今年的國小生與今年的大專生
   是不同的人。兩者相除既不是升學率也不是流失率，本專案刻意不輸出任何跨階相除的數字。
3. **單一學年。** 與大專那筆同樣的限制，理由見上一節第 1 點。
4. **沒有族別。** 四筆都沒有族別欄位。

四筆的原始統計機關同為教育部統計處，**四階彼此一致不構成交叉驗證**。

### ⚠️ 地理流動這份資料的三個限制

1. **一般生對照：流出端沒有，承接端有。**
   出生戶籍地端做不出來——全體學生的開放資料裡沒有出生地。

   ⚠️ **【2026-08-11 更正】原本這裡寫「沒有一般生對照」，並說學校所在地端
   「要另外一份校址對照表」。兩句都錯。** `student.json`、`103-112_student.json`、
   `sdata.json`、`graduate.json` **四個檔本來就有 `縣市名稱` 欄位**（值長成
   `01 新北市`，去掉數字前綴即可 join），不需要任何額外資料。

   已補上 `一般生學校所在地數` 與 `集中倍數`（＝原民占全國比 ÷ 一般生占全國比）。
   ⚠️ 一般生端只含大專校院，**所以原民端必須配 `A1-6a` 而不是 `A1-6b`**。
   總計層級兩者差距不大（25,613 vs 27,347），但二專差很多（288 vs 800）。
2. **表頭與總計列的位置逐年會動。** `A1-5` 的總計列 104–108 在第 5 列、109 起在第 6 列；
   `A1-6b` 的表頭列 110 學年是第 4 列、其餘年是第 5 列。一律依內容定位，不可寫死列號。
   同一列表頭裡，在學欄寫「博士班」、畢業欄寫「博士」，左右兩半不對稱。
3. **這兩張表沒有 109 學年的二專斷點。** 因為範圍含空大及進修學校，109 那次
   「附設進修專校併回母校」的搬家在總數上互相抵銷（二專全國 961 → 935 → 1010，平滑）。
   上面「用之前先看這三件事」的二專警語**不適用於這一節**。

**獨立交叉驗證：** `A1-6a` 的全國各等級別數字，與本專案原本從 `A1-1` 校別＋`sdata`
算出來的 `out/compare_national.csv`，**106–114 學年 × 5 個等級別共 45 個數字全部相符**。
兩者來自出版品的不同 sheet、經過完全不同的處理路徑，這構成有效的交叉驗證。

### ⚠️ 存量那份資料的四個限制

1. **基準日是民國 113 年 12 月底，不是學年度。** 這是人口統計的存量，教育部那邊是
   學年度的在學人數，**不可以畫在同一條時間軸上**，也不能互相當分子分母。
2. **本專案目前只做到縣市層級——這是選擇，不是資料的限制。**
   我們取的是「**統計區**」版，空間單元只有一級／二級發布區，代碼長成 `A1501-24`：
   `A` ＋ 縣市序號 ＋ 2 碼鄉鎮序號。縣市可以還原（`A15` → 10015 花蓮縣，見各檔
   `Info.InCountyId`），但那 2 碼是 SEGIS 內部序號、不是 8 碼行政區代碼，
   接不回鄉鎮市區，**所以這個版本只能到縣市**。

   ⚠️ **【2026-08-11 更正】先前這裡寫成「資料只能到縣市」，那是錯的。**
   同一份統計還有「**行政區**」版，空間統計單元直接就是**縣市／鄉鎮市區／村里**，
   不需要任何對照表。要下鑽到鄉鎮或村里，改抓那個版本即可。兩版的取捨：

   | | 行政區版 | 統計區版（本專案採用） |
   | --- | --- | --- |
   | 空間單元 | 縣市／鄉鎮市區／**村里** | 一級／二級發布區／最小統計區 |
   | 最新期別 | 112 年 12 月 | **114 年 12 月** |

   當初是用關鍵字搜尋撈到統計區版，沒有查證有沒有行政區的雙胞胎。
   平台的《產品總目錄》一頁就看得到兩者並列，
   **要找 SEGIS 的資料先查那份目錄，不要用關鍵字亂撈。**
   目錄的 PDF 版就在本庫根目錄（`STATCatalog.pdf`，384 頁，3,044 筆），不必再去下載。
3. **沒有族別，也沒有平地／山地之分**，只有「原住民」整體。
4. **目前只取一期，但它其實有時間序列。** 97 年 12 月起、多數年份一年兩期
   （06、12 月）。本專案把它當單一切片處理，所以存量那一區是排行榜而不是趨勢線。

### 存量那份的資料來源與取用上的坑

`https://data.gov.tw/api/v2/rest/dataset/18672` — 《統計區原住民 15 歲以上人口
十歲年齡組與性別與教育程度人口統計》，內政部統計處，經社會經濟資料服務平台（SEGIS）供應。

- **沒有縣市級彙總檔。** 44 個 distribution ＝ 22 縣市 × 一級／二級發布區，
  縣市數字只能自己把幾千列加起來。
- **宣告格式不可信。** 44 條全部宣告為 XML，實際上「新北市_一級發布區」回傳 JSON。
  `build_education.py` 一律嗅探首個非空白位元組。
- **一級 ⊂ 二級發布區**，彙總到縣市必須得到同一組數字。兩級都抓齊時
  （`python fetch_segis.py --level both`，約 450MB）建置腳本會自動互相驗證，
  這是唯一查得出「發布區漏列」的方法。**已實測 22 縣市全數一致。**
- 預設只抓二級發布區（53MB）就夠了，一級只是驗證用。
- **平台上有《產品總目錄》**，逐列列出每個資料集的中類／小類／名稱／時間／
  空間範圍／空間統計單元／欄位清單，共 3,044 筆。**本庫根目錄放了一份 PDF 版**
  （`STATCatalog.pdf`，384 頁，2026-08-09 更新），平台查詢介面另可下載
  同內容的 `STATCatalog.xlsx`——要程式化篩選就用 xlsx，它有欄位結構。
  **要在 SEGIS 找資料，先查這份目錄**——關鍵字搜尋會漏掉同名不同版本的資料集
  （本專案就漏了行政區版，見上方更正）。

依授權規定，引用時須標示來源為**社會經濟資料服務平台**或**內政部統計處**。

## 其他口徑注意事項

- **分母含境外生**：全體學生數包含僑生、外國生、陸生，所以占比是「占全體在學生」而非「占本國生」，會略微低估。
- **二專在 109 學年有口徑斷點**（`compare_national.csv` 的「口徑註記」欄已標）。109 學年起「○○科技大學附設進修專校」不再是獨立學校，學生改列母校進修部：
  - 學校名錄「空大及大專附設進修學校」108 學年 91 校 → 109 學年 28 校，消失的 63 校裡 40 校是附進修專校
  - 全體二專分母同時 4,784 → 12,144；原民端則是類別間搬家（大專校院 356→599、空大及進修學校 605→336，合計 961→935 持平）
  - 分子分母跳增幅度不同，占比從 7.44% 假性掉到 4.93%。**108 以前與 109 以後不可直接比較**，且分母端無法回補
- **空大與宗教研修學院沒有分母**：`compare_by_school.csv` 有 411 列有原民生卻對不到全體數，全國彙總已排除。
- **博碩士的「延修生」不可比**：全體檔那兩欄一律為 0（研究生不用該欄表示），原民檔卻有值。`compare_grade.csv` 已濾掉分母為 0 的列。
- **校別資料 104–114**。opendata 的 `A1-1` 只更新到 113，114 是從出版品的 A1-1 解析補上的；
  重疊的 104–113 每一年都拿來對帳，數字與 opendata 完全相同（`build.py` 不符會出聲）。
- **性別只交叉到等級別**。出版品的 `A1-3`（學門）與 `A1-4`（科系）都沒有性別欄，
  全體端的 `sdata` 也沒有——所以「原民生念什麼科系、男女差在哪」在公開資料裡做不出來。
  教育部的互動圖表有 114 學年前 10 大細學類按性別分，但沒有對應的開放資料。
  （`graduates.json`／[dataset 9619](https://data.gov.tw/dataset/9619) 有科系 × 性別，
  但只有**畢業生**且只有**全體**，原民端仍是空的，湊不成對比。）
  性別這一塊的口徑反而比學門分析乾淨：兩邊都只含大專校院，沒有分子分母範圍不一致的問題。

### 併表時做的正規化

- **學校代碼**：當年度 `student.json` 沒補零（`"1"`），歷年檔與原民檔是 `"0001"` — 一律 zfill(4)
- **等級別**：全體檔用代碼前綴（`D/M/B/C/2/5/X`），`B 學士`、`B 四技`、`C 二技`、`C 二年制`、`X 4+X` 全歸「學士班」，`5 五專`、`5 七年` 歸「五專」
- **`A2-3` 的等級別用詞逐年變動**（`大學四年制`／`大學四年制(或四技)`／`學士班`／`二技`／`4+X`），另做對照表收斂
- **日間∕進修別**：原民檔不分，全體檔加總後再比
