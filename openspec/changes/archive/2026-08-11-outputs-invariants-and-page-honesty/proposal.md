## Why

2026-08-11 一天內新增五個報告區塊，留下兩筆債。

**一、頁面的自我描述已經與內容不符。** 「縣市」頁的開場白仍寫「這一頁把**三件事**
放在一起看」，但該頁現在有 **10 個區塊**；byline 的資料來源仍只列
`A1-5／A1-6b ＋ 統計區原住民教育程度人口統計`，而當天新接的四個來源
（行政區各級學校統計四筆、`edu_A_1_7`、`base3`）一個都沒列。
讀者最先看到的兩段文字，描述的是一個已經不存在的頁面。

**二、沒有任何自動化檢查，而本專案的風險正好是「靜默壞掉」。** 當天至少四次
靠人工比對才發現問題：行政區版存量的縣市歸屬錯位（內部一致但對外全錯）、
占比的兩次四捨五入、spec 範例寫成 −11.5（實為 −11.6）、範例表填了未實算的數字。
**這些都不會讓任何程式報錯。**

專案現有 11 支建置腳本、21 個輸出檔，關鍵數字之間有硬約束：

| 不變量 | 值 |
| --- | ---: |
| 大專原民生（承接端）＝ `A1-6a` 逐縣市 | 25,613 |
| 高中職原民生 ＝ 就學階梯高中職列 | 20,398 |
| 原住民 15 歲以上人口（存量） | 490,336 |
| 有該階學校的鄉鎮市區數（遞減） | 367 → 357 → 206 → 87 |
| 全國原始占比 ＝ 年齡標準化占比（恆等） | 35.00% |

這些約束目前只存在於各腳本的執行期檢查與我的記憶裡。來源改版時，
輸出可能變成「看起來合理但錯」，而沒有任何東西會亮紅燈。

## What Changes

- 新增一套回歸測試，把上述不變量與各輸出檔的形狀釘住，直接跑在**已入版控的
  `out/` CSV** 上，不需要重跑 pipeline 或連網。
- 修正「縣市」頁的開場白與 byline，使其如實描述目前的區塊與資料來源。
- 新增一條規範：日後在報告頁新增區塊時，開場白與來源列必須同步更新，
  並由測試檢查兩者的一致性。

## Non-Goals

- 不測建置腳本的內部函式。測的是**輸出的不變量**，那才是口徑錯誤會現形的地方。
- 不新增資料、不改任何既有數值、不改頁面的圖表與敘事。
- 不做 CI 設定。本輪只提供可在本機執行的測試。
- 不重排區塊順序，也不把全國性的分流區塊搬離「縣市」頁。

## Capabilities

### New Capabilities

- `output-invariants`: 輸出檔之間的硬約束與形狀檢查，以可執行的測試表達，
  跑在版控的 CSV 上、不需連網。
- `report-self-description`: 報告頁的開場白與資料來源列必須如實反映目前的區塊
  與來源，且新增區塊時同步更新。

### Modified Capabilities

(none)
